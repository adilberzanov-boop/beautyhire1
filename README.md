# 💇‍♀️ BeautyHire

**Платформа, где бьюти-салоны находят мастеров, а мастера — работу. Плюс онлайн-запись клиентов в салон.**

🔗 **Живая ссылка:** `<ВСТАВЬТЕ_ССЫЛКУ_ПОСЛЕ_ДЕПЛОЯ>`

## Проблема
В Алматы тысячи салонов и мастеров, но искать друг друга они вынуждены в Instagram-чатах и Telegram-группах: нет единой базы вакансий, портфолио и отзывов. Салоны теряют время и деньги на пустые кресла, мастера — на поиск подходящего места.

## Решение
BeautyHire — маркетплейс «салон ↔ мастер»:
- **Мастер**: профиль с портфолио, навыками, желаемой зарплатой, отклики на вакансии.
- **Салон**: профиль, вакансии, поиск мастеров по фильтрам, приглашения.
- **Чат** между салоном и мастером по каждому отклику.
- **Онлайн-запись клиентов** в салон (услуги, расписание, депозит).
- **Отзывы и рейтинги**, Premium-продвижение вакансий.
- **Email-уведомления** (EmailJS).

## Архитектура
| Слой | Технология |
|---|---|
| Фронтенд | HTML + JavaScript (SPA), Tailwind CSS, Swiper |
| Бэкенд / API | **Supabase** (PostgreSQL + автогенерируемый REST API (PostgREST) + Auth + Storage) |
| Безопасность | Row Level Security: политики доступа на каждую таблицу (`db/schema.sql`) |
| Хостинг | Vercel / Netlify / GitHub Pages (статика) + Supabase Cloud (бэкенд) |

База данных (8+ таблиц): `profiles`, `master_profiles`, `salon_profiles`, `vacancies`, `applications`, `messages`, `reviews`, `portfolio_photos`, `services`, `salon_availability`, `bookings`.

Серверная логика: регистрация и вход (Supabase Auth), CRUD-эндпоинты к таблицам, правила доступа (RLS: например, переписку видят только участники отклика), загрузка файлов в Storage.

## Запуск локально
```bash
git clone <repo-url>
cd BeautyHire
# просто откройте index.html или:
npx serve .
```
Ключи Supabase находятся в `config.js` (публичный `anon/publishable` ключ — он предназначен для браузера, доступ ограничен RLS).

## Развёртывание своего экземпляра
1. Создать проект на supabase.com
2. SQL Editor → выполнить `db/schema.sql`
3. Storage → бакет `avatars` (public)
4. Вписать URL и ключ в `config.js`
5. Задеплоить папку на Vercel/Netlify
Подробно: [`docs/SETUP.md`](docs/SETUP.md)
